# Optimal GT Designer documentation

Optimal GT Designer is this fork of [GT Plus](https://github.com/Coow/GT-Plus), an editor for vMix GT Title
Designer templates (`.gtzip`). These pages cover what the fork adds.

**Golden rule:** no feature changes how a `.gtzip` is written or how vMix reads it. Everything is saved with
structures GT already has, and editor-only aids such as the reference image are never written into the file.

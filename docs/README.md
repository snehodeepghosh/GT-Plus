# Optimal GT Designer documentation

Optimal GT Designer is this fork of [GT Plus](https://github.com/Coow/GT-Plus), an editor for vMix GT Title
Designer templates (`.gtzip`). These pages cover what the fork adds. Everything it saves is still a normal `.gtzip`
that vMix GT Title Designer opens.

| Page | What it covers |
| --- | --- |
| [Ribbon interface](ribbon.md) | The GT-style ribbon and where each command lives |
| [Photoshop import](psd-import.md) | Importing `.psd`/`.psb` files, including clipping masks |
| [Masks](masks.md) | How object masks are drawn on the canvas |
| [Effects](effects.md) | Skew, Reflection and Texture Flip |
| [Timeline](timeline.md) | The Figma-style timeline, detaching it, the working area and the resizable bar |
| [Canvas](canvas.md) | Drag-to-move and the canvas background |
| [macOS](macos.md) | Shortcuts on a Mac, the app name and icon, building the `.app` |

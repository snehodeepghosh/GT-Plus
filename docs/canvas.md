# Canvas

## Moving objects

With the **Select** tool, drag an object to move it. You no longer need to switch to the Edit tool.

- **Shift-click** adds an object to the selection or removes it.
- **Cmd-drag** (Ctrl-drag on Windows) on empty canvas draws a selection box.
- Locked objects and objects on locked layers don't move.
- Objects don't move while a storyboard preview is showing.

## Background

**View › Background** switches what shows behind the title:

- **Grid**: the transparency checkerboard.
- **Black**: solid black, the way the title will key over black in vMix.

The grid's colours and size and the solid colour can be changed in Preferences.

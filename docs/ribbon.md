# Ribbon interface

The menus and side toolbars are replaced by a ribbon laid out like vMix GT Title Designer's, with a dark theme.

## Tabs

- **File**: new, open, save, save as, recent files and Import PSD.
- **Home**: undo and redo, the clipboard, and layer commands.
- **Styles**, **Format**, **Effects**, **Animations**, **Data**: the same groups as in GT Title Designer.
- **View** (Optimal GT Designer only): rulers, guides, snap, pixel grid, the canvas background, and preferences.

## How groups behave

- Each group holds up to three rows of controls above a caption, as in GT.
- When the selection can't use a group, the group is greyed out rather than hidden, so the layout never shifts.
